# Hangman Game (Java)

## Overview

This project is a feature-rich **Hangman Game** developed using **Java**. The game provides an interactive and enjoyable word-guessing experience while tracking player performance through statistics and rankings.

Players can choose different categories and difficulty levels, use a hint when needed, and compete for the highest score on the leaderboard.

---

## Features

### 🎮 Classic Hangman Gameplay
- Guess the hidden word one letter at a time.
- Limited number of incorrect guesses.
- Win by correctly guessing the complete word before running out of attempts.

### 🏆 Leaderboard System
- Stores the history of players who have played the game.
- Ranks players based on the number of correctly guessed words.
- Allows users to compare their performance with other players.

### 📊 Player Statistics
- Displays Tops player performance records.
- Shows which player has the highest number of correctly guessed words.
- Helps track game progress and achievements.

### 📂 Category Selection
Players can choose their preferred category before starting the game, making the gameplay more personalized and engaging.

Example categories may include:
- Animals
- Countries
- Technology
- Sports
- Foods

### 🎯 Difficulty Levels
Players can select a difficulty level according to their preference:

- Easy
- Medium
- Hard

Different difficulty levels provide varying word complexities and challenges.

### ⏱ Timer Feature
- A countdown timer is integrated into the game.
- Encourages faster decision-making.
- Adds excitement and challenge to gameplay.

### ❌ Wrong Guess Tracker
- Displays all incorrectly guessed letters.
- Improves the overall user experience.

### 💡 Hint System
- Every player receives **one hint per game**.
- The hint can assist players when they are struggling to guess the word.
- Limited to maintain game balance and challenge.

## Technologies Used
